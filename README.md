# 🍵 Çay Koymadan Hiçbir Şey Yapmayan Algoritma

## Resmi Bilimsel Manifesto

Bu repository, insanlık tarihinin en büyük bilimsel keşiflerinden biridir. Yıllar süren (aslında 3 dakika) araştırmalar sonucu ortaya çıkan bu algoritma, **çay koyulmadan hiçbir işin yapılamayacağını** matematiksel olarak kanıtlamaktadır.

### Neden Bu Kadar Önemli?

- Çay, evrenin temel sabiti olarak kabul edilmelidir (Planck sabiti yerine Çay sabiti).
- Bürokrasi, iş, kod, aşk, savaş, barış... Hepsi çay olmadan anlamsızdır.
- Bu kod, Türkiye Cumhuriyeti'nin resmi olmayan ama çok ciddi çay protokolünü uygulamaktadır.

### Nasıl Kullanılır?

1. Python 3 yüklü olsun (olmasa da çay koy).
2. `python cay_algoritmasi.py` çalıştır.
3. Sorulan soruya **evet** de. Yoksa program kendini feda eder.
4. Çay koyduğunu onayladıktan sonra abartılı hesaplamaları izle.

### Uyarı

Bu algoritma çok güçlüdür. Yanlış kullanım durumunda demlik patlayabilir. Sorumluluk tamamen kullanıcıya aittir.

## Katkıda Bulunmak

Pull request'ler kabul edilir, ama sadece çay koyduğunu kanıtlayanlar.
